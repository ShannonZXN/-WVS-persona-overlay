# WVS Population Persona Overlay

This repository contains the working files and outputs for the WVS population persona overlay used in the project.

## Folder structure

### 01_metadata
Metadata-augmented files, variable summaries, and error code details.

### 02_input_data
Input data used for variable selection, including the 304 candidate variables, 20 core questions, and WVS Wave 7 input materials.

### 03_python_code
Python scripts used for preprocessing, imputation, clustering, plotting, and result summarisation.

### 04_original_results
Original clustering result tables from Test 1, Test 2, and Test 3.

### 05_final_results
Final selected results for Test 1, k = 4, including:
- 1_Respondent_Level_Cluster
- 2_Cluster_Summary
- 3_Cluster_Profile
- 4_Persona_Summary1
